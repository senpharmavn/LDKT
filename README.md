# Lãnh Đạo Khai Tâm (LDKT)

Source code cho hệ thống Lãnh Đạo Khai Tâm của SEN Pharma.

## Thành phần

- `app/`: ứng dụng học viên Next.js và Google Apps Script backend.
- `instructor-dashboard-prototype/`: dashboard giảng viên Next.js.
- `student-report-share/`: trang chia sẻ báo cáo học viên.
- `tools/`: script hỗ trợ tạo dữ liệu và tài liệu phát hành.

## Bảo mật và triển khai

Các file môi trường, token, cấu hình Vercel cục bộ, build output và dữ liệu/báo cáo học viên không được lưu trong repository. Xem `app/docs/deployment-notes.md` để biết cấu hình cần thiết khi triển khai.
